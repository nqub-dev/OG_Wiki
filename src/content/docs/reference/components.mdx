## Callouts

<Callout type="note">Neutral context that's useful but not urgent.</Callout>
<Callout type="tip" title="Do this">
  The recommended path.
</Callout>
<Callout type="warning" title="Careful">
  Something that commonly goes wrong.
</Callout>
<Callout type="danger" title="Stop">
  Destructive or irreversible.
</Callout>

```mdx
<Callout type="tip" title="Do this">
  The recommended path.
</Callout>
```

Types: `note` (default), `tip`, `warning`, `danger`. `title` is optional.

## Steps

<Steps>

1. Clone the template.
2. Edit `wiki.config.ts`.
3. Replace the contents of `src/content/docs/`.
4. Deploy the `dist/` folder anywhere static.

</Steps>

```mdx
<Steps>

1. First thing
2. Second thing

</Steps>
```

<Callout type="note" title="Blank lines matter">
  Leave an empty line after `<Steps>` and before `</Steps>` so MDX parses the list as Markdown
  rather than raw JSX.
</Callout>
